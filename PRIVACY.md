# Privacy Policy — Minimal IG

Minimal IG è progettata secondo i principi di Privacy by Design e Local-First.

## Principi Fondamentali
1. Zero Raccolta Dati: Nessun dato personale, credenziale o metadato viene raccolto.
2. Zero Analytics o Tracker: L'applicazione non include SDK di terze parti o strumenti di telemetria.
3. Zero Credenziali Memorizzate: L'autenticazione avviene interamente sui server ufficiali di Meta (instagram.com).
4. Nessun Backend Proprietario: Il codice funziona interamente all'interno del browser del tuo dispositivo.
5. Storage Locale Esclusivo: Le impostazioni sono salvate esclusivamente nel localStorage del browser.
