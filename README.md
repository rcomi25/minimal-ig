# Minimal IG — Guida all'Installazione

1. Carica la cartella `minimal-ig` su GitHub Pages o Cloudflare Pages (HTTPS gratuito).
2. Installa l'estensione gratuita **Userscripts** da App Store su iPhone.
3. Scarica ed importa `minimal-ig.user.js` in Userscripts.
4. Apri l'URL HTTPS della PWA su Safari su iPhone, premi **Condividi > Aggiungi alla schermata Home**.
